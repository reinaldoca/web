# **App Name**: Tech Solutions AR

## Core Features:

- Homepage Messaging: Prominent display of a value proposition tailored to the Argentine market.
- Service Listing: Showcase IT support, cloud migration, DevOps, cloud engineering, and security services.
- Success Stories: Feature testimonials and case studies from Argentine SMEs.
- Contact Form: A simple contact form with direct access to WhatsApp Business.
- Blog: Resources and articles focused on cloud, DevOps, and security for Argentine IT managers.  LLM tool for content planning
- Automated Ticket Generation: Automatically creates new tickets from contact form submissions

## Style Guidelines:

- Primary color: Dark blue (#224270) to evoke trust and professionalism.
- Background color: Light gray (#F0F4F7), almost white, for a modern, clean backdrop.
- Accent color: Steel gray (#607D8B) to add a high-tech touch without being distracting.
- Font: 'Lato' (sans-serif) for body and headline, requested by user. Note: currently only Google Fonts are supported.
- Use technology-themed icons, plus AWS/DevOps badges.
- Modern, minimal design for conveying technological competence.
- Subtle transitions and animations to indicate interactivity without distracting.
